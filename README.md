# Skills personnels

Dépôt privé : plugin `tn-seo`, avec les 10 skills personnels, `maj-templates`, la charte et le logo Suisseo.

## Installer

`/plugin marketplace add tom-ned/tn-skills` puis `/plugin install tn-seo` (le compte doit avoir accès au dépôt).

Pour Claude.ai : zipper le contenu de `tn-seo/` et l'importer comme plugin.

Les modèles se règlent avec le skill `maj-templates`.
